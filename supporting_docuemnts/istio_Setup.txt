for this project we need istiod services. 

Istiod is handling ineternal Traffic. 
Istio-gateway is handling external traffic we have already created alb ingress-controller for 
external traffice. but here we need Istio-Gateway for Argorollouts canary deployments. 

kubectl delete crd $(kubectl get crd | grep istio.io | awk '{print $1}')

helm repo add istio https://istio-release.storage.googleapis.com/charts
helm repo update
kubectl create namespace istio-system


helm install istio-base istio/base -n istio-system --set defaultRevision=default


helm install istiod istio/istiod -n istio-system --wait
